# News reader

SSR news aggregator

## Features

- News search and filtering
- Pagination
- URL-based filters and pagination
- Multiple news display modes
- Display mode persistence via `localStorage`

## Development Requirements

This project was developed using `vite-plus` to [manage Node.js and npm versions](https://viteplus.dev/guide/env).

[Install `vite-plus`](https://viteplus.dev/guide/#install-vp), or ensure your local Node.js and npm versions match the `devEngines` requirements in `package.json` if you manage them manually.
